# Soporte

¿A dónde llevar cada solicitud?

| Necesito… | Canal |
| --- | --- |
| Reportar un error en una aplicación | Abre un issue en su repositorio con la plantilla **Reportar un error**. |
| Proponer una mejora o funcionalidad | Abre un issue con la plantilla **Solicitar una funcionalidad**. |
| Reportar una vulnerabilidad de seguridad | Sigue la [política de seguridad](SECURITY.md). **No uses issues.** |
| Acceso a un repositorio o a una aplicación interna | Pídeselo a tu líder de equipo. |
| Información sobre planes, afiliaciones o citas | [bionicavisions.com.co](https://bionicavisions.com.co) o [WhatsApp](https://wa.me/573182000009). |
| Peticiones, quejas, reclamos o solicitudes sobre tus datos personales | Sección **PQRS** de [bionicavisions.com.co](https://bionicavisions.com.co). |
