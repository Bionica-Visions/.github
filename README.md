# Bionica-Visions/.github

Repositorio de configuración común de la organización **Biónica Visions** en GitHub.

| Ruta | Para qué sirve |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Presentación pública que aparece en [github.com/Bionica-Visions](https://github.com/Bionica-Visions). |
| [`SECURITY.md`](SECURITY.md) | Cómo reportar vulnerabilidades. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Ramas, commits, pull requests y revisión de código. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Normas de convivencia del equipo. |
| [`SUPPORT.md`](SUPPORT.md) | A dónde acudir según el tipo de solicitud. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Formularios para reportar errores y pedir funcionalidades. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Lista de verificación para cada pull request. |
| [`workflow-templates/`](workflow-templates/) | Flujos de GitHub Actions listos para usar en los repositorios de la organización. |

Los archivos de comunidad (seguridad, contribución, código de conducta, soporte y plantillas) se
aplican de forma automática a todos los repositorios de la organización que no tengan su propia
versión. Si un repositorio necesita reglas distintas, basta con agregar ahí su propio archivo.

Para cambiar algo, abre un pull request contra `main` siguiendo la
[guía de contribución](CONTRIBUTING.md).
